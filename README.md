## Projet MLOps : Modèle de Prédiction de Défaut de paiement
### Aperçu du Projet
Ce projet met en œuvre une démarche MLOps de bout en bout pour développer, tracker et déployer un modèle de Machine Learning destiné à prédire le risque de défaut de paiement sur des prêts personnels pour une banque de détail.

*L'objectif* est de fournir une estimation de la probabilité de défaut pour chaque client, permettant à l'équipe de risque d'allouer le capital de manière appropriée et de maintenir la stabilité financière.
